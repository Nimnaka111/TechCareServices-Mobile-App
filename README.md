# TechCare Services Mobile Application

## Overview
TechCare Services is an Android mobile application developed for the Mobile Application Development (MAD) module. The application allows users to access and manage technical service providers efficiently.

## Features
- User registration and login
- Service provider management
- Service booking
- Profile management
- Android-based user interface

## Technologies Used
- Java
- Android Studio
- Firebase
- Gradle
